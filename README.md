# equity-research-data

JSON output from an automated equity-research agent. A scheduled task runs on weekdays at about 6:30am ET, follows [`CLAUDE.md`](CLAUDE.md), and commits the results to `main`.

## Reading it from a website

Start at **`data/index.json`**. It has one summary row per stock and a pointer to that stock's `latest.json`.

```
data/index.json                  -> list of stocks (price, stance, conviction, fair value, next earnings, headline)
data/<TICKER>/latest.json        -> everything a stock page needs + links to every detail file
data/<TICKER>/thesis.json        -> pillars, risks, falsifiers, append-only log
data/<TICKER>/catalysts.json     -> event calendar (upcoming + occurred with outcomes)
data/<TICKER>/notes/<date>.json  -> daily morning notes
data/<TICKER>/earnings/<Q>.json  -> post-earnings analysis
data/<TICKER>/previews/<Q>.json  -> pre-earnings preview
data/<TICKER>/model.json         -> estimates + change history
data/<TICKER>/initiation.json    -> full initiation report
data/runs/<date>.json            -> what ran on each day and whether it succeeded
```

Every file has `type`, `ticker`, `as_of`, `generated_at`, `summary`, `sources` and `disclaimer`. Longer prose, where there is any, is in `body_md` (markdown). The full contract is in [`schema/research.schema.json`](schema/research.schema.json).

**Fetching:** this repo is private, so `raw.githubusercontent.com` URLs need a token. Choose one:
- fetch server-side with a read-only fine-grained token: `GET https://api.github.com/repos/brk-kzc/equity-research-data/contents/data/index.json` with `Accept: application/vnd.github.raw`;
- make the repo public and read `https://raw.githubusercontent.com/brk-kzc/equity-research-data/main/data/index.json`;
- or have your site's build step clone or pull the repo.

## Adding stocks

Add an entry to `config/watchlist.json`. On the next run, the agent initiates coverage for it (initiation, model, thesis, catalysts) and then puts it on the normal cycle.

## Local commands

```
python3 scripts/er.py plan [--date YYYY-MM-DD]   # what the agent will do on a given day
python3 scripts/er.py build                      # rebuild latest.json + index.json
python3 scripts/er.py validate                   # schema-check every file
```

*Automated research output generated by an AI agent from public sources. Not investment advice.*
